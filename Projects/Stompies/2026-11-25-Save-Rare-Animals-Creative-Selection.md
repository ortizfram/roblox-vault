## Decision
First 10: RUN 1/4/7/10, GROW 2/5/8, SAVE 3/6/9. If budget small test 1/2/3 first; use 4/5/6 for next variants. 11–23 reserve not initial spend. No egg imagery, no claims of false rarity, stats or unimplemented abilities. Compare actual live game with image (giant stomp, geometry, pet models, baby→adult sizes, glowing fence and color variants); if mismatch hold asset. Art direction: blocky Roblox + voxel pets, bright color, one clear action, size contrast and mobile readability. Preserve original game identity rather than copying competitors. Use cleaner renders as controls; no assumption AI effects outperform them.
Pre-launch gates: verify first rescue, growth, placement and second run on mobile; D1 and session time versus comparable game benchmarks, telemetric events. Goal Plays if approved, same audience/period/bid conditions; measure impressions, CTR, plays, CPP, playtime/D1 by available cohorts. Give attribution time to mature (post-click reporting up to 48h); compare enough impressions and avoid daily winner changes. Rank is not actual performance; no spend, no publish, no new game title selected. ZIP binary and contact sheet delivered in chat, not stored in this markdown vault.
